# Archivist Study Flashcards

Cards for studying for the Certified Archivists exam. These "terms/concepts" were culled from the ACA Exam Study Guide 2025. I may have added to them. Definitions are taken from various publications but often [the SAA Dictionary](https://dictionary.archivists.org/). ~~I didn't bother to cite my sources (sorry!)~~ I am trying to cite my sources!

These cards assume you're using [`hashcards`](https://github.com/eudoxia0/hashcards) for studying. See the installation instructions there. Usage:

```sh
hashcards drill ./cards # quiz yourself
hashcards browse ./cards # browse existing cards
hashcards --help # further commands
```

You essentially rate how confident you feel as you drill and the app automatically returns to topics where you are less sure of yourself.

## Notes

[tbd-cards](./tbd-cards.md) contains terms I haven't written the definition for yet. Move them to [cards/archivist-certification.md](./cards/archivist-certification.md) when done. Changing a card's `Q` is like changing it's identifier; all stats are reset. Run `hashcards orphans delete ./cards` to delete orphaned (previous version) cards afterwards.
